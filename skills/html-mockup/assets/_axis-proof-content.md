# Axis proof — the shared content set

The copy for ONE fictional client, rendered by BOTH `proof-editorial-mockup.html`
(`PERS-EDITORIAL`) and `proof-direct-mockup.html` (`PERS-DIRECT`). Every string below appears
here **once**, and both files render these exact strings in this exact section order.

That is the whole point. The falsifiable claim behind the perceptual axes is *same content, same
sections, two personalities → unmistakably different pages*. If the two files were allowed to
differ in a single word, a section, or a card count, any difference a reader saw could be the
copy rather than the axes, and the proof would prove nothing. This file is what makes the
comparison honest: it is the constant, and the five axes are the only variable.

Client profile: a stone fabricator (marmolería). Chosen because it is one of the real client
profiles this framework serves — alongside law firms and voice actors — and because it is the
opposite of the SaaS aesthetic the anchors must not collapse back into. Copy is Spanish, matching
the client profiles this framework serves; the client profile is Spanish. Placeholder imagery
only, per the `.ph` recipe in `references/mockup-guide.md` — no photo is part of the comparison.

Neither file is a client mockup. They are single-page axis proofs, so the one-Artifact multi-page
contract in `SKILL.md` does not apply to them; they are read side by side, not navigated.
